# Optional creation and research tools

Install only what the actual job needs. These accounts and tools are not installed by the skill or repository installer. Verify current versions, rights, costs and permissions on their official sites.

| Optional route | Useful for |
|---|---|
| Existing OpenAI image tool / ChatGPT Images | Image generation and reference-based edits |
| Gemini / Nano Banana / Nano Banana 2 | Alternative still generation and editing |
| Higgsfield | Approved illustrative stills through the account's available models |
| Claude Design | Brand-grounded visual exploration, layouts and supported exports |
| Superwhisper | Dictating a brief, and transcribing a spoken one |
| A connected video provider (Seedance, Kling, Veo, Gemini Omni, Wan and others) | Generated motion clips, when one is actually connected |
| A connected speech provider (ElevenLabs, OpenAI speech and others) | Narration, voice previews and voice cloning of the user's own voice |
| Remotion | Editable motion, captions and programmatic composition |
| FFmpeg | Assembly, encoding, and the measurable checks on duration, loudness and sync |
| Blender | 3D when the idea materially needs it |
| Public Meta Ad Library browser access / available research connector | Actual competitor-ad observations |
| Authorized Meta Marketing API/MCP | Account data and explicitly authorized campaign operations |

The still packs list the image routes, the video packs list the motion and speech routes, and neither lists the other's: a pack that names a provider it has no workflow for is promising something it cannot finish. The runtime provider guide inside each pack contains source links and checks. Missing access produces a concrete capability gap, not a fabricated result. Never paste keys into a skill, chat transcript or public repository. A provider switch or new account must fit the user's generation approval. At zero Higgsfield credits, offer a legitimate funded account switch by the user, reduced scope or another approved route.
