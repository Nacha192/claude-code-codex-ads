Install only what the actual job needs. These accounts and tools are not installed by the skill or repository installer. Verify current versions, rights, costs and permissions on their official sites.

| Blender | 3D when the idea materially needs it |

Video and voice tools are deliberately absent: Seedance, Kling, ElevenLabs, OpenAI speech and Remotion belong to the video pack. The runtime provider guide inside each pack contains source links and checks. Missing access produces a concrete capability gap, not a fabricated result. Never paste keys into a skill, chat transcript or public repository. A provider switch or new account must fit the user's generation approval. At zero Higgsfield credits, offer a legitimate funded account switch by the user, reduced scope or another approved route.
