# What this pack builds

**Still creative: images and carousels.** One frame that has to work before anyone
decides to keep looking.

Motion, narration, music and anything that runs on a timeline belong to the
motion packs in this same repository. They are not half-covered here, on purpose:
a reference that mentions storyboards without carrying the craft produces
confident advice about a job the pack cannot finish, which is worse than an
honest gap.

If the request is a video ad, say so in one sentence and use a `video-ads-*`
edition instead of improvising from these references. They are installed the same
way, from the same repository, and they share this contract.

The artifact checker in every pack accepts a `storyboard` kind because the code is
shared. Producing one from a still-creative pack is out of scope: hand the job to
the motion edition rather than writing half a video plan here.
