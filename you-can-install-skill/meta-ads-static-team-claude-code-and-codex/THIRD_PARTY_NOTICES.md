# Source attribution and boundaries

The MIT license covers this repository's original implementation and synthesized instructions. Upstream skills, tools, models and assets retain their own licenses and terms. They are not relicensed by this repository. No upstream scripts, private chats or client media are redistributed.

The full source inventory includes author/repository, exact entrypoint, pinned commit, capture date, content hash, license reported by GitHub and an original adaptation note. See [research/sources.json](https://github.com/Nacha192/claude-code-codex-ads-static/blob/main/system/research/sources.json) and each installed skill's `references/source-catalog.md`. Repository-level license detection is not a legal audit of every file; `UNKNOWN`/`NOASSERTION` means permission was not established by that metadata.

Sources adapted in this still-creative pack include Corey Haines, Alireza Rezvani, Rob Palmer, Hyper, Anthropic, OpenAI, inference.sh, AgriciDaniel, realkimbarrett, buluslan, Zubair Trabzada, avectats7, sergebulaev, yaxeen, Gooseworks and norahe0304-art.
